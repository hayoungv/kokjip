# 확정 문구

바깥에 내보이는 문장이다. **글자 그대로 쓴다.** 줄이거나 바꿔 쓰지 않는다.

---

## 카피 문구

> **강의에서 다시 볼 것만 콕.**

## 서비스 설명

> **콕집은 매일 쌓이는 강의를 처음부터 다시 볼 필요 없이, 지금 다시 봐야 할 내용만 골라 필요한 부분부터 효율적으로 복습할 수 있도록 도와주는 학습 서비스입니다.**

---

## 쓰는 곳

| 자리 | 쓰는 문장 |
|---|---|
| 화면 제목과 브라우저 탭 | 콕집 |
| 첫 화면의 큰 글씨 | 카피 문구 |
| 첫 화면의 설명 줄 | 서비스 설명 |
| 문서와 소개 자료의 첫 문단 | 서비스 설명 |

## 이 문장이 강사 발화를 말하지 않는 이유

가치 제안 문서는 이 제품의 값을 두 겹으로 나눠 두었다.

| 겹 | 내용 | 어디에 쓰는가 |
|---|---|---|
| 바깥 | 남은 시간 안에 끝낸다 | 처음 만나는 사람에게 건네는 말 |
| 안쪽 | 강사가 실무 중요도를 직접 말한 말을 근거로 삼는다 | 제품이 실제로 도는 방식 |

확정 문구는 바깥 겹이다. 처음 보는 사람이 자기 문제로 알아들을 수 있는 말이어야 하기 때문이다. 안쪽 겹은 제품을 열어 복습 목록을 본 순간 드러난다. 목록의 각 줄에 강사의 말이 그대로 붙어 있기 때문이다.

## 쓰지 않는 말

가치 제안 문서의 가드레일을 그대로 따른다.

| 쓰지 않는다 | 왜 | 대신 쓴다 |
|---|---|---|
| 인공지능이 강의에서 중요한 내용을 골라 줍니다 | 기계가 임의로 판단하는 것으로 읽힌다 | 강사님이 실무에서 중요하다고 강조한 구간을 찾아 드립니다 |
| 강의에서 불필요한 내용을 잘라내 버립니다 | 강사의 강의를 깎아내리는 말이 된다 | 가용 시간에 맞춰 가장 먼저 볼 구간을 정해 드립니다 |
| 콕집을 쓰면 취업이 보장됩니다 | 증명할 수 없다 | 현직자 강사의 실무 감각과 팁을 놓치지 않고 복습합니다 |
| 인공지능이 요약 노트와 문제를 만들어 드립니다 | 무료 도구와 구분이 사라진다 | 강사의 실제 발화를 근거로 복습 순서를 세워 드립니다 |
