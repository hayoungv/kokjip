## 프로토타입을 쓰는 범위

프로토타입은 화면의 짜임새와 말투를 참고하는 용도다. **확정된 요구사항과 어긋나는 부분은 요구사항을 따른다.**

어긋나는 곳은 다음과 같다.

| 항목 | 프로토타입 | 따르는 것 |
|---|---|---|
| 올리는 것 | 녹음 파일을 서버로 올린다 | **글만 올린다.** 음성은 기기에만 둔다 |
| 처리 대기 | 음성 전사를 기다리는 화면이 있다 | **전사가 기기에서 끝나** 기다릴 것이 없다 |
| 유형 이름 | MUST, CORE, PRACTICAL, AVOID | **한국어 표기**를 쓴다 |
| 강도 | 유형 옆에 숫자가 붙는다 | 요구사항에 강도가 없다 |
| 근거 범위 | 구간으로 보여준다 | 발화 지점 하나를 저장한다 |
| 강사 화면 | 로그인과 대시보드가 있다 | **계정 없이 전용 주소**로 동의와 차단만 |

## 브랜드를 쓰는 방식

색은 `src/app/globals.css`에 디자인 토큰으로 옮겨 두었다. 화면에서는 그 토큰 이름으로 쓴다.

| 쓰임 | 토큰 |
|---|---|
| 제목과 본문 | `text-navy` |
| 행동을 부르는 곳 | `bg-brand` · `text-brand` · `bg-brand-soft` |
| 완료와 정상 | `text-mint` · `bg-mint-soft` |
| 강조 포인트 | `text-accent` |
| 바탕 | `bg-canvas` · `bg-surface` |
| 선 | `border-line` |
| 보조 설명 | `text-muted` |
