# 운영 문서

제품을 무엇으로 만들지가 아니라, **만들어진 제품이 돌 때 사람이 무엇을 하는지**를 적는다.

[`AGENTS.md`](../../AGENTS.md) §5-6은 과정 개설·학습자 초대·재적 인원 집계·청구서 발행을 첫 버전에서 제품 기능으로 만들지 않고 사람이 처리한다고 정했다. 그 "사람이 처리한다"의 내용이 여기에 있다.

PRD·SRS·TDS와 앞뒤 순서 관계가 없다. 확정된 제품 동작을 전제로 그 바깥을 채운다.

| 파일 | 답하는 질문 |
|---|---|
| [`lagging-learner-response.md`](lagging-learner-response.md) | 뒤처짐 신호가 떴을 때 누가 무엇을 하는가 |
| [`instructor-consent-notice.md`](instructor-consent-notice.md) | 강사에게 녹음 허용을 어떻게 요청하는가 |
| [`field-interview-guide.md`](field-interview-guide.md) | 확인하지 못한 값을 현장에서 어떻게 채우는가 |

---

## 이 문서들이 지키는 것

- 제품 동작은 `AGENTS.md` §5를 따른다. 여기서 제품 동작을 새로 정하지 않는다.
- 화면에 이미 있는 문구는 화면이 기준이다. 여기 옮겨 적은 문장이 화면과 다르면 화면이 맞다.
- 담당자가 그대로 꺼내 쓸 수 있는 형태로 쓴다. 절차서에는 판단 기준과 대본과 양식을 함께 넣는다.
- 확인하지 못한 것은 확인하지 못했다고 적는다. 각 문서 끝에 그 목록을 둔다.
