# 뒤처짐 신호 대응 절차

| | |
|---|---|
| 문서 종류 | 운영 절차서 |
| 버전 | 1.0 |
| 기준 시점 | 2026년 9월 |
| 답하는 질문 | 뒤처짐 신호를 받은 뒤 누가 무엇을 하는가 |
| 쓰는 사람 | 훈련기관 운영 담당자 |

---

## 1. 목적

훈련기관 화면에 올라온 뒤처짐 신호를 실제 개입으로 바꾼다. 신호를 보는 것으로 끝나면 중도 탈락은 줄지 않는다. 이 문서는 신호를 받은 담당자가 무엇을 확인하고, 무엇을 말하고, 무엇을 남기는지를 정한다.

---

## 2. 이 절차가 다루는 신호

### 2-1. 제품이 주는 것과 주지 않는 것

| 주는 것 | 주지 않는 것 |
|---|---|
| 수강생 이름 | 출결 기록 |
| 며칠째 복습 목록을 열지 않았는지 | 과제 제출 여부 |
| 마지막으로 연 날 | 성적과 평가 |
| 강사의 녹음 허용 상태 | 강의 내용과 복습 목록의 내용 |

기관 화면에는 강의 기록이 나오지 않는다. 담당자가 수강생이 무엇을 공부했는지 들여다보는 경로는 없다.

### 2-2. 판정 기준

복습 목록 화면을 **3일 연속 열지 않으면** 뒤처지는 것으로 본다. 연속된 날은 **강의가 올라온 날만** 센다. 강의가 없는 날은 연속을 끊지도 올리지도 않는다.

강사가 막은 회차는 녹음이 올라오지 않아 회차 자체가 만들어지지 않는다. 그런 날은 애초에 세지 않으므로 따로 걸러 낼 필요가 없다.

### 2-3. 이 신호를 무엇으로 읽는가

**신호는 단서이지 판정이 아니다.** 복습 목록을 열지 않은 것과 훈련을 놓고 있는 것은 다르다. 앱을 아직 깔지 않았을 수도 있고, 기기를 바꿨을 수도 있다. 둘을 가르는 자리가 1단계다.

이 신호가 다른 지표와 다른 점은 하나다. **출석하고 있는 사람에게도 켜진다.** 출결로는 아무 문제가 없어 보이는 구간을 메우는 것이 이 신호의 쓸모다.

---

## 3. 대응 단계

| 단계 | 시점 | 하는 일 | 드는 시간 |
|---|---|---|---|
| 1. 사실 대조 | 신호 당일 | 출결·과제·상담 이력과 맞춰 보고 오탐을 거른다 | 1인당 5분 |
| 2. 1차 연락 | 1영업일 안 | 문자를 먼저 보내고, 무응답이면 전화한다 | 1인당 10분 |
| 3. 대면 확인 | 3영업일 안 | 강의장 밖에서 짧게 만난다 | 1인당 15분 |
| 4. 조치 합의 | 대면 자리에서 | 다음 주에 할 일을 하나만 정한다 | — |
| 5. 재확인 | 7일 뒤 | 신호가 꺼졌는지 본다 | 1인당 3분 |
| 6. 종결 또는 상위 보고 | 재확인 직후 | 꺼지면 닫고, 그대로면 팀장에게 올린다 | — |

### 3-1. 1단계 — 사실 대조

아래에 해당하면 연락하지 않고 닫는다. 닫은 이유를 기록에 남긴다.

| 거르는 경우 | 어디서 확인하는가 |
|---|---|
| 앱을 아직 설치하지 않았다 | 화면에 "복습 기록 없음"으로 나오고 마지막 열람일이 비어 있다 |
| 기기를 바꿨거나 로그인이 풀렸다 | 본인에게 한 번 확인한다 |
| 결석 사유를 이미 받았다 | 출결 기록 |
| 이미 상담이 진행 중이다 | 상담 기록 |

"복습 기록 없음"이 여러 명에게 한꺼번에 나오면 개인 문제가 아니다. 앱 설치 안내가 닿지 않은 것이므로 개별 연락 대신 공지를 다시 한다.

### 3-2. 2단계 — 1차 연락

**감시로 느끼게 하지 않는다.** 복습 목록을 열지 않았다는 사실을 그대로 들이대면 수강생은 감시받는다고 느끼고 앱을 지운다. 앱을 지우면 신호 자체가 사라져 그다음부터는 아무것도 보이지 않는다. 연락의 목적은 확인이 아니라 회복이다.

문자 대본이다.

```text
○○○님, 훈련팀 △△△입니다.
이번 주 진도가 좀 빡빡했죠. 따라가시는 데 어려움은 없으신지 궁금해 연락드렸습니다.
막히는 부분 있으시면 편하게 말씀 주세요. 내일 쉬는 시간에 잠깐 뵈어도 좋고요.
```

전화에서 묻는 것은 세 가지다.

1. 지금 어디가 막히는지
2. 복습할 시간이 나는지
3. 그만둘 생각을 해 본 적이 있는지

세 번째를 피하지 않는다. 직접 묻지 않으면 그만두겠다는 말을 통보로 처음 듣게 된다.

하지 않는 말이다.

| 하지 않는다 | 왜 | 대신 |
|---|---|---|
| 앱을 사흘째 안 여셨네요 | 감시로 들린다 | 요즘 진도 따라가시기 어떠세요 |
| 복습 안 하시면 수료가 어렵습니다 | 위협이 되고, 사실도 아니다. 수료 기준은 출석이다 | 복습할 시간이 잘 안 나시는 편인가요 |
| 다른 분들은 다 하고 있어요 | 비교는 이탈을 앞당긴다 | ○○○님 속도에 맞춰 조정해 볼까요 |

### 3-3. 3단계 — 대면 확인

강의장 밖, 다른 수강생이 듣지 않는 자리에서 만난다. 5분이면 된다. 자리를 길게 잡으면 다음번에 피한다.

### 3-4. 4단계 — 조치 합의

다음 주에 할 일을 **하나만** 정한다. 여러 개를 정하면 하나도 하지 않는다.

| 사유 | 합의할 수 있는 조치의 예 |
|---|---|
| 학습 난이도 | 강사에게 해당 단원 보충을 요청한다. 스터디에 연결한다 |
| 시간 부족 | 이번 주 복습 범위를 목록 상위 3개 항목으로 줄인다 |
| 건강·개인 사정 | 출결 조정을 안내한다. 필요하면 훈련 연기를 상담한다 |
| 취업 활동 | 일정을 공유받고 결석 처리 방식을 안내한다 |
| 과정 불만 | 들은 말을 그대로 적어 과정 운영에 올린다 |
| 진로 변경 | 붙잡지 않는다. 중도 탈락 절차를 정확히 안내한다 |
| 연락 두절 | 수단을 바꿔 3회까지 시도하고 상위에 보고한다 |

마지막에서 두 번째 줄이 중요하다. 이미 다른 길을 정한 사람을 붙잡으면 남은 사람에게 쓸 시간이 사라진다.

## 4. 사유 분류

기록할 때 붙이는 코드다. 개인을 보지 않고 분포를 본다.

| 코드 | 사유 |
|---|---|
| A | 학습 난이도 |
| B | 시간 부족 |
| C | 건강·개인 사정 |
| D | 취업 활동 |
| E | 과정 불만 |
| F | 진로 변경 |
| G | 연락 두절 |
| H | 오탐 (1단계에서 닫음) |

A가 몰리면 과정 편성 문제이고, E가 몰리면 운영 문제다. H가 많으면 이 절차의 판정 기준을 손봐야 한다.

## 6. 주기 점검

| 주기 | 하는 일 |
|---|---|
| 매일 | 기관 화면을 한 번 연다. 새로 뜬 신호만 본다 |
| 매주 월요일 | 미종결 건을 훑고 7일이 지난 재확인을 처리한다 |
| 기수 종료 | 사유 분포·종결율·오탐 비율을 정리해 과정 운영에 올린다 |

---

## 7. 이 절차에서 하지 않는 것

- 신호를 수료 판정이나 평가에 쓰지 않는다. 수료 기준은 출석이며 이 신호와 무관하다.
- 신호를 점수나 등급으로 바꾸지 않는다.
- 강사에게 개인 이름을 넘기지 않는다. 보충이 필요하면 단원 단위로 요청한다.
- 복습 목록의 내용을 담당자가 보려 하지 않는다. 기관 화면에는 나오지 않는다.
