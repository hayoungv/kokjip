# 도메인 계층

업무 규칙이 사는 곳이다. 화면이나 요청 형식이나 데이터베이스를 알지 않는다.

여기에 들어가는 함수는 값을 받아 값을 돌려줄 뿐이고, 바깥을 부르지 않는다. 그래야 데이터베이스 없이 시험할 수 있다.

## 파일

| 파일 | 담는 규칙 |
|---|---|
| `types.ts` | 이 계층이 쓰는 타입 |
| `range.ts` | 시각 구간 정리와 차집합 |
| `canonical.ts` | 정본 선정과 처리 대상 산출 |
| `time.ts` | 실제 시각과 경과 시각 변환 |
| `lag.ts` | 뒤처짐 판정 |

## 왜 여기만 시험을 촘촘히 까는가

이 네 규칙이 틀리면 이런 일이 생긴다.

- 같은 구간을 두 번 처리해 판정 비용이 샌다
- 처리해야 할 구간을 빠뜨려 복습 목록에 구멍이 생긴다
- 재생 위치가 어긋나 엉뚱한 곳이 재생된다
- 뒤처지지 않은 학습자가 뒤처진 것으로 올라간다

넷 다 화면에서는 늦게 드러난다. 그래서 여기서 잡는다.

## 시험 돌리기
